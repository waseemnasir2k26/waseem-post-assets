# waseem-post-assets

Curated image pool for SkynetLabs' LinkedIn auto-poster (n8n LI-01/LI-02).
Public so the n8n LinkedIn node can fetch each image as binary and upload it to LinkedIn.
These are professional/public-facing photos, already intended for social posting.

## Status

Last reviewed: October 2026 · release v2026.10

`img/` — 25 rotation images, LinkedIn-optimized (max 1600px, ~85% JPEG).
`manifest.json` — list of `file` / `category` / `url` entries for each image, used by the drafter.
